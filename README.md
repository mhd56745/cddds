# koyeb-tv — منصة قنوات بث 24/7 بأسلوب Viloud (على Koyeb، بدون ffmpeg)

منصة تلفزية مصغرة تعمل بـ **nginx + nginx-vod-module فقط**، مع **لوحة تحكم عربية**:
مكتبة فيديو تُغذّى بروابط مباشرة، قنوات بقوائم تشغيل تتكرر 24/7، قنوات إعادة بث
خارجية (m3u8/TS)، روابط HLS جاهزة لكل قناة، مشغّل ويب، وكود تضمين iframe.

## أولاً: الرفع إلى GitHub ثم Koyeb

ارفع **كل** الملفات التالية إلى المستودع (مثل `mhd56745/sdd`) عبر Upload files:

```
Dockerfile
.dockerignore
nginx/nginx.conf.template
scripts/entrypoint.sh
scripts/admin.py
scripts/build_schedule.py
scripts/gen_locations.py
scripts/mp4_info.py
scripts/media_fetch.py
www/index.html
www/admin.html
www/watch.html
www/embed.html
media/            (اختياري — فارغة أو بملفات MP4)
```

> ملاحظة: احذف الملفات القديمة `scripts/gen_restream.py` و `scripts/restream_env.py`
> إن كانت لا تزال في المستودع — لم تعد مستخدمة.

في Koyeb أنشئ Service من GitHub، Dockerfile build، منفذ **8000**.

## متغيرات البيئة (إعدادات الخدمة في Koyeb)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ADMIN_PASSWORD` | `admin123` | كلمة مرور لوحة التحكم — **غيّرها** (اتركها فارغة = بلا حماية) |
| `APP_NAME` | `قناتي` | اسم المحطة في العناوين |
| `SEED_JSON` | — | بيانات تصدير JSON لاستعادة القنوات والمكتبة عند كل إقلاع |
| `MAX_VIDEO_MB` | `1024` | الحد الأقصى لحجم الفيديو الواحد |
| `MAX_LIBRARY_MB` | `2048` | الحد الأقصى لحجم المكتبة كاملة |
| `MEDIA_URL` | — | (توافق قديم) روابط تنزيل عند الإقلاع |
| `RESTREAM_URL`…`RESTREAM_URL_8` | — | (توافق قديم) تُرحَّل تلقائياً إلى قنوات |
| `SEGMENT_DURATION` | `10000` | مدة مقطع HLS بالمللي ثانية |
| `SCHEDULE_INTERVAL` | `15` | دورة تجديد خرائط البث بالثوان |

## الاستخدام

1. افتح `https://<تطبيقك>.koyeb.app/admin/` وسجّل الدخول.
2. تبويب **مكتبة الفيديو**: أضف فيديو باسمه ورابطه المباشر (MP4 H.264/AAC).
   يُنزَّل إلى الخادم ويُفحص تلقائياً (المدة والترميزات — بدون ffmpeg).
3. تبويب **القنوات**: أنشئ قناة نوع «قائمة تشغيل 24/7» ورتّب فيها فيديوهات
   المكتبة، أو قناة «بث خارجي» برابط m3u8/TS.
4. تنشر كل قناة رابط **m3u8** ثابتاً + صفحة مشغل `/watch/<id>` + كود تضمين
   iframe جاهز للصق في أي موقع.

## الروابط

| الرابط | الوصف |
|---|---|
| `/` | صفحة القنوات والمشغّل |
| `/admin/` | لوحة التحكم |
| `/watch/<id>` | صفحة مشاهدة قناة (مع «يُبث الآن») |
| `/embed/<id>` | مشغّل مدمج للتضمين |
| `/live/<id>/master.m3u8` | رابط قناة مكتبة (HLS) |
| `/restream/<id>/...` | رابط قناة بث خارجي عبر وكيل محطتك |
| `/healthz` | فحص صحة Koyeb |

## النسخ الاحتياطي (مهم على Koyeb)

تخزين Koyeb مؤقت يُمسح مع كل نشر جديد. من تبويب **النسخ الاحتياطي** في اللوحة:
صدّر البيانات وضعها في متغير البيئة `SEED_JSON` — عند كل إقلاع تعود القنوات
تلقائياً وتُعاد تنزيل الفيديوهات من روابطها (خلف الكواليس).

## الصيغ المدعومة

- **مدعوم**: MP4/MOV/M4V بفيديو H.264 (avc1) وصوت AAC/MP3/AC3 — والبث الخارجي m3u8 أو TS.
- **غير مدعوم**: H.265/HEVC، DTS/Opus/TrueHD، MKV بترميزات غريبة، روابط magnet
  (تحتاج عميل تورنت — خارج نطاق المحطة الخفيفة)، وملفات MKV بفيديو H.264 تُقبل
  لكن الأفضل إعادة تغليفها إلى MP4 خارجياً.

## البنية التقنية

- `nginx` (1.28) + `nginx-vod-module` وضع mapped/live: يعيد تغليف MP4 إلى HLS-TS
  مباشرة من الملفات — **بدون ffmpeg نهائياً**.
- `admin.py` (بايثون قياسي فقط، لا مكتبات خارجية): واجهة `/api/`، تنزيل الفيديوهات،
  مجدول يولّد خرائط البث كل 15 ثانية بخوارزمية حتمية (أرقام تسلسلية متسقة عبر
  إعادة التشغيل)، ثم `gen_locations.py` يولّد مواقع nginx و `nginx -s reload`.
- البيانات: `/data/videos.json` و `/data/channels.json` والخرائط في `/var/vod/maps/live/<id>`.
